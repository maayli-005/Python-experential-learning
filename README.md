# Python Experiential Learning

## Student Marksheet Automation (High Volume)

This repository contains the work completed for the Python Programming
Language Experiential Learning Project.

## Project Overview

Student Marksheet Automation is a Python-based system designed to automate
marksheet preparation for a large number of students.

The system automatically processes student marks and generates:

- Total Marks
- Percentage
- Grade
- Rank
- Result

## Objectives

- Automate marksheet generation for multiple students.
- Calculate total marks automatically.
- Calculate percentage accurately.
- Assign grades based on percentage.
- Determine student rank.
- Reduce manual calculation errors.
- Process multiple student records efficiently.
- Generate clear marksheet information.

## Technologies Used

- Python
- Lists and Dictionaries
- Loops
- Conditional Statements
- Sorting
- File Handling

## Project Workflow

Student Details
